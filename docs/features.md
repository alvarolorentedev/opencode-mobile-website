# OpenCode Mobile features and workflow guides

Start with the outcome you need. Each guide explains when the capability is useful, the exact mobile workflow, what you should see, and the important limitations.

## I want OpenCode to work on something

Use [Start and Monitor Tasks](./guides/tasks.md) to choose an agent and model, write a useful prompt, attach context, follow live progress, stop a bad direction, and decide when the result is actually complete.

## I want to continue or reorganize existing work

Use [Manage Sessions](./guides/sessions.md) to switch, rename, share, archive, restore, delete, fork, or revert sessions without losing track of the active project.

## OpenCode is waiting for me

Use [Approvals and Changes](./guides/approvals-and-changes.md) to understand permission choices, answer product questions, review diffs, and avoid approving a risky action by habit.

## I cannot conveniently type

Use [Voice and Conversation Mode](./guides/voice.md) to dictate a reviewed draft or run the foreground listen → submit → wait → speak loop.

## The session is getting long or expensive

Use [Understand Session Usage](./guides/usage.md) to interpret context utilization, input/output/reasoning tokens, cache activity, steps, and provider cost estimates.

## I need to inspect or adjust a file

Use [Work with Files](./guides/workspace-files.md) to search the active project, read a file, and save a small text patch with a server-side conflict check.

## I need to run a command

Use [Use the Terminal](./guides/terminal.md) for tests, status checks, short logs, and non-interactive project commands—and to understand why full-screen terminal programs are not a good fit.

## I need isolated parallel work

Use [Manage Worktrees](./guides/worktrees.md) to create, reset, or remove experimental OpenCode worktrees safely.

## A model is missing or a provider needs sign-in

Use [Providers and Models](./guides/providers-and-models.md) to distinguish server authentication from AI-provider authentication, complete OAuth/manual setup, and control which models appear in Chat.

## Tools or realtime updates are not behaving as expected

Use [MCP and Diagnostics](./guides/mcp-and-diagnostics.md) to manage MCP servers and inspect OpenCode health, realtime fallback, LSP, and formatter information.

## I want to leave while a task runs

Use [Task Notifications](./guides/notifications.md) to enable Android alerts, adjust system/battery settings, and understand when delivery may be delayed.

## I cannot connect to the server

Use [Remote Access](./remote-access.md) for trusted LAN, Tailscale, Cloudflare Tunnel, reverse proxy, API-prefix, and SSH-forwarding setup and troubleshooting.
