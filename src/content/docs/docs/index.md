OpenCode Mobile is a community-built Android and iOS client for an [OpenCode](https://opencode.ai/) server that you run yourself. This documentation covers installing the app, connecting it to your server, configuring providers, securing remote access, and fixing connection problems.

OpenCode Mobile is **not** an official OpenCode product, a hosted AI service, or a replacement for the OpenCode server.

## How the pieces fit

| Piece | What it is | Where it runs |
| --- | --- | --- |
| OpenCode Mobile | The mobile client you install | Android or iOS |
| OpenCode server | The coding agent that owns your project | Your machine |
| Connection route | LAN, VPN, tunnel, proxy, or SSH forward | Between the two |

The app is a remote control. Your repository, provider credentials, build tools, and complete development environment stay on the machine that runs OpenCode.
