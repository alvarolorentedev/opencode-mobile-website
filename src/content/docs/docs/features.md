## I want OpenCode to work on something

Use [Start and Monitor Tasks](/docs/guides/tasks/) to choose an agent and model, write a useful prompt, attach context, follow live progress, stop a bad direction, and decide when the result is actually complete.

## I want to continue or reorganize existing work

Use [Manage Sessions](/docs/guides/sessions/) to switch, rename, share, archive, restore, delete, fork, or revert sessions without losing track of the active project.

## OpenCode is waiting for me

Use [Approvals and Changes](/docs/guides/approvals-and-changes/) to understand permission choices, answer product questions, review diffs, and avoid approving a risky action by habit.

## I cannot conveniently type

Use [Voice and Conversation Mode](/docs/guides/voice/) to dictate a reviewed draft or run the foreground listen → submit → wait → speak loop.

## The session is getting long or expensive

Use [Understand Session Usage](/docs/guides/usage/) to interpret context utilization, input/output/reasoning tokens, cache activity, steps, and provider cost estimates.

## I need to inspect or adjust a file

Use [Work with Files](/docs/guides/workspace-files/) to search the active project, read a file, and save a small text patch with a server-side conflict check.

## I need to run a command

Use [Use the Terminal](/docs/guides/terminal/) for tests, status checks, short logs, and non-interactive project commands—and to understand why full-screen terminal programs are not a good fit.

## I need isolated parallel work

Use [Manage Worktrees](/docs/guides/worktrees/) to create, reset, or remove experimental OpenCode worktrees safely.

## A model is missing or a provider needs sign-in

Use [Providers and Models](/docs/guides/providers-and-models/) to distinguish server authentication from AI-provider authentication, complete OAuth/manual setup, and control which models appear in Chat.

## Tools or realtime updates are not behaving as expected

Use [MCP and Diagnostics](/docs/guides/mcp-and-diagnostics/) to manage MCP servers and inspect OpenCode health, realtime fallback, LSP, and formatter information.

## I want to leave while a task runs

Use [Task Notifications](/docs/guides/notifications/) to enable native alerts, adjust platform settings, and understand when delivery may be delayed.

## I cannot connect to the server

Use [Remote Access](/docs/remote-access/) for trusted LAN, Tailscale, Cloudflare Tunnel, reverse proxy, API-prefix, and SSH-forwarding setup and troubleshooting.
